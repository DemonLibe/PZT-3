## Решения, принятые с человеком
- Git-операции делает ИИ; человек только забирает изменения через Терминал (`git clone` один раз, потом `git pull`) — человек не хочет ставить GitHub Desktop
- Рабочая ветка: `claude/new-session-2cfd7a`
- Клавиши привязаны по физическим кодам (physical_keycode) — работают при русской раскладке
- Тестовая комната собрана из CSGBox3D с коллизией — быстро для прототипа, позже уровни будут из мешей
- Автозагрузки без `class_name` — иначе Godot ругается на конфликт имени с синглтоном
