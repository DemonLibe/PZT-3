# Автотесты

Каждый тест — сцена `tN.tscn`; запуск без окна:

```bash
godot --headless --path . res://debug/tests/t4.tscn
```

В конце печатается `ИТОГ: все проверки пройдены` или число проваленных проверок.

| Тест | Что проверяет |
| --- | --- |
| t2 | управление, взгляд, шум, фонарь |
| t3 | система аномалий (красный куб) |
| t4 | «Зеркало» |
| t5h + t5c | сеть: сначала `t5h` (хост), через 3 с во втором окне `t5c` (клиент) |
| t6 | отряд NPC, команды, навигация |
| t7w, t7d, t7s, t7sh | «Окна», «Ужин», «Сон», «Тень» |
| t8c, t8w | «Колыбель», «Смотритель», двери |
| t9, t9b | цикл экспедиции, журнал, Энциклопедия; `t9b` после `t9` — сохранение на диск |
| t10 | сквозной проход всех направлений через меню |
| t11 | точки фиксации |
| t12–t29 | районы 3, 4, 7, 9, 10, 11, 12, 13, 14, 16, 18, 20, 21, 24, 25, 27, 28, 30 |
| t30–t40 | секции Гигадома 30, 31, 33–35, 37–50 |
