# Модели локаций ПЗМ-3 (v2)

88 low-poly объектов в стиле PS1 для трёх ярусов: `districts/` (районы 01–30, 32 шт.), `gigadom/` (секции 30–50, 28 шт.), `lake/` (острова 51–70, 28 шт.).
Формат `.glb` (glTF 2.0) — Godot импортирует сам. Текстуры встроены в файлы.

## Что нового в v2
- Процедурные PS1-текстуры 32–128 px: бетон с подтёками, крашеные стены, плитка, дерево, ржавый металл, ткань, кирпич, мрамор, листва и т.д. Фильтр nearest, UV в метрах — плотность одинаковая на всех моделях.
- Фаски на мебели и рамах, неровная органика (кроны, камни, туши, свёртки).
- Детализация: у панельки — балконы, рамы, водостоки, кондиционеры, антенны; у коридоров Гигадома — крашеная панель, трубы, кабельный лоток, лужи, трап; сервировка на всех местах «Ужина» и стулья; и т.д.
- Новые объекты: `kitchen_stove`, `crt_tv`, `stairwell_flight`, `concrete_stairs`, `barrel_rusty`, `metal_cabinet`.

## Правила
- Метры, Y вверх, точка опоры — центр основания. Потолочные (висят вниз от точки опоры): `pendant_lamp_red`, `ceiling_stain`, `fluorescent_lamp`, `meat_hook_rail`, `sinew_ceiling`, `cocoon`.
- Коллизии внутри: узлы `-convcolonly` → `StaticBody3D` с выпуклой формой. Мелочь без коллизий.
- Материалы: цвет белый × текстура — `RetroRender` передаёт текстуру в `ps1_surface.gdshader`. Светящиеся (`window_lit`, `fluorescent`, `sodium`…) — emission без текстуры.
- Модули Гигадома 4×4×3 м — ставить вплотную каждые 4 м по Z.

## Посмотреть
`showroom.tscn` — все модели рядами с подписями. Превью — `_previews/`. Список с размерами — `manifest.json`.

## Пересобрать
    blender -b -P tools/model_gen/build_models.py -- assets/models/locations
(или `pip install bpy` и `python3 tools/model_gen/build_models.py assets/models/locations`). Ручные правки .glb при пересборке пропадут.
